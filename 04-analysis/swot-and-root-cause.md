# SWOT Analysis & Root Cause Analysis

## SWOT Analysis – Current Order Fulfillment Capability

**Strengths**
- Experienced warehouse team
- Established supplier relationships
- Growing online sales channel

**Weaknesses**
- Manual processes and paper-based operations
- Poor real-time inventory visibility
- High order cycle time and error rates
- Siloed systems (e-commerce, POS, warehouse)

**Opportunities**
- Implement modern WMS/IMS to gain competitive advantage
- Improve customer satisfaction and NPS
- Reduce operational costs through efficiency
- Scale operations without proportional headcount increase

**Threats**
- Competitors offering same-day / next-day delivery
- Rising customer expectations
- Potential loss of market share due to poor fulfillment experience
- Increasing labor costs

---

## Root Cause Analysis (5 Whys) – Long Order Cycle Time

1. **Why** is average order cycle time 4.8 days?  
   → Because allocation and picking take too long.

2. **Why** does allocation take long?  
   → Because supervisors manually check stock and create lists.

3. **Why** is it manual?  
   → Because there is no system that shows real-time available inventory.

4. **Why** is there no real-time inventory?  
   → Because current tools only update in batches and systems are not integrated.

5. **Why** are systems not integrated?  
   → Because the company has grown faster than its technology foundation (no prior investment in modern IMS).

**Root Cause:** Lack of integrated, real-time inventory management system and supporting digital processes.
