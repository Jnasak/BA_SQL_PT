# Business Analysis Project: Improving Order Fulfillment at NovaMart Retail

**Project Type:** End-to-End Business Analysis  
**Domain:** Retail / E-commerce Operations  
**Status:** Complete Example (ready to clone & customize)

---

## Project Overview

NovaMart is a mid-sized online + offline retail company selling electronics, home goods, and apparel.  
The company is experiencing delayed order fulfillment, high return rates, and poor inventory visibility, which is affecting customer satisfaction and increasing operational costs.

This repository contains a **complete Business Analysis project** that walks through the full BA lifecycle:

1. Discovery & Stakeholder Analysis  
2. Requirements Elicitation & Documentation  
3. Process Modeling (As-Is → To-Be)  
4. Gap Analysis & Solution Recommendation  
5. Delivery Planning & UAT  

You can clone this repo and adapt it for your own BA portfolio, school project, or real client work.
